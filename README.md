# Pomodoro Cube Timer 
It is a simple clock made using esp32s3. It can function for more than that 

## Description 
This project is there to teach me C++ and make a useful timer that helps me focus. It sets an automatic alarm based on the basis or it orientation 

## [![Watch the video](https://youtube.com)](https://youtube.com/shorts/fYHEk9lXrdg)

## Getting Started 
As this project is still in the starting phase. I used a simple esp32s3, in combination with a round display(1.28inch tft) and simple gyro(MPU6050)
